# Система управления интернет-магазином и складом
## 1. Язык и версия
Проект разработан на Python 3 и использует стандартные библиотеки Python.

## 2. Структура проекта
```
atributes.py    #Классы атрибутов Price, Quantity и Weight
product.py      #Абстрактный базовый класс Product
products.py     #Классы товаров Smartphone, Laptop, Tshirt, Jacket, Milk и Bread
factories.py    #Фабрики для создания товаров
warehouse.py    #Склад и собственный итератор
main.py         #Демонстрация работы программы
```
## 3. Запуск программы
Перейти в каталог проекта и запустить программу
```python
python3 main.py
```

## 4. Архитектура
* Price, Quantity и Weight - отдельные классы для проверки и хранения атрибутов товара
* Product - абстрактный базовый класс для всех товаров, определяет общий интерфейс
* Smartphone, Laptop, Tshirt, Jacket, Milk и Bread - конкретные классы товаров
* ProductFactory - абстрактный класс с методом создания товара.
* ElectronicsFactory, ClothesFactory, FoodFactory - фабрики категорий, создающие соответствующие типы товаров
* WarehouseIterator - собственный итератор для последовательного перебора товаров
* Warehouse - класс склада, отвечающий за хранение, поиск, добавление, удаление и перемещение товаров

Для проекта был выбран порождающий паттерн Фабричный метод. Каждая фабрика отвечает за создание своей категории, абстрактный класс определяет единый интерфейс создания. Фабричный метод был выбран вместо Абстрактной фабрики, так как в проекте нет необходимости создавать целые семейства товаров.

## 5. Демонстрационные сценарии
**Сценарий 1: Создание склада и работа с товарами.** Проверяется работа фабрик, добавление товара на склад, изменение цены и количества, удаление товара со склада, перебор товара с помощью итератора с поиском по категории.

**Сценарий 2: Копирование склада.** Создается глубокая копия склада, после чего проверяется независимость исходного склада и копии.

**Сценарий 3: Перемещение между складами.** Демонстрируются перемещение товаров между складами.
